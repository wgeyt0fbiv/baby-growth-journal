# 【通知】全国男性健康日惠民活动

> 更新时间：2026-09-16 (UTC+8)

今年10月28日第25个“全国男性健康日”，主题是“人口发展高质量，男性健康全周期”，男性作为人口发展的重要组成部分，其健康状况直接影响到家庭幸福、社会稳定和人口发展的可持续性，旨在呼吁社会关注男性健康问题，提高男性健康意识，促进家庭和谐，倡导健康生活方式。我院生殖健康与不孕症科在“全国男性健康日”来临之际，**特举办系列惠民活动。**

**义诊时间**

2024年10月28日 

**义诊地点**

青海省妇幼保健院住院部六楼生殖健康与不孕症科

**义诊范围**

1.男性不育类疾病（弱精子症、少精子症、无精子症、死精子症、精液不液化、畸形精子症等）。

2.前列腺病（前列腺炎、前列腺增生、前列腺癌等）。

3.精囊、精索及输精管类疾病（精索静脉曲张、精囊炎、鞘膜积液等）。

4.阴茎、阴囊类疾病（外阴炎、阴茎硬结症、阴茎短小症、嵌顿包茎、阴囊瘙痒、阴囊湿疹等）。

5.睾丸及附睾类疾病（睾丸炎、隐睾症、睾丸外伤、睾丸萎缩、睾丸及附睾肿瘤、睾丸扭转、附睾炎等）。

6.男性性功能障碍（勃起功能障碍、早泄、阴茎异常勃起、不射精症、性欲低下、性欲亢进、逆行射精、射精疼痛等）。

7.男科杂病（遗精、血精、男性乳腺发育、性早熟等）。

8不孕症（各种原因所致不孕如多囊卵巢综合征、卵巢功能低下、盆腔炎症性不孕等）。

9.胎停育类疾病（如复发性流产等）。

10.女性性功能障碍（性欲障碍、性交疼痛等）。

11.小儿泌尿外科疾病（疝气、肾积水、鞘膜积液）、包皮疾病（包茎、包皮过长、包皮囊肿，包皮黑色素痣）

**义诊活动**

1. 义诊的前20名患者免挂号费。

2. 当天义诊的前20名男性患者，可免费专科体检一次；前10名前列腺患者，可免费获“绿色疗法”1次；前5名男性不育患者，可免费化验精液常规分析1次；前5名性功能障碍患者，可享受性功能康复理疗1次。

3. 根据病情需要免费体验中医特色疗法1次，如穴位贴敷、耳穴压豆、放血疗法、皮内针治疗等。

4. 生殖健康科各诊室就诊的前5名女性患者，可免费妇科检查1次。

5. 当天在生殖健康科义诊的儿童患者可免费生殖健康专科体检一次。
